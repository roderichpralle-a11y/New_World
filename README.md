# Insel-Siedler

Ein gemütliches Aufbauspiel in Pixel-Grafik: Zwei Siedler stranden auf einer Insel,
sammeln Rohstoffe, bauen Hütten, bekommen Kinder und wachsen über Generationen.

**Spielen:** https://roderichpralle-a11y.github.io/New_World/ (PC und Handy)

Gebaut mit Godot 4.7. Architektur und Regeln: [DESIGN.md](DESIGN.md). Quellen: [CREDITS.md](CREDITS.md).
